🎥 How to Embed a YouTube Video

A step-by-step guide for beginners

Introduction

Embedding a YouTube video allows you to display a video directly on your website. Follow these five easy steps to add a video to your HTML page.

Step 1: Open YouTube

Visit YouTube and search for a family-friendly video that you want to add to your website. Open the video.

Step 2: Click the Share Button

Under the video, click the Share button. A sharing window will appear with different options.

Step 3: Select Embed

In the sharing window, select Embed. YouTube will display HTML iframe code for your video. If Embed is not available, choose a different video.

Step 4: Copy the Embed Code

Click the Copy button next to the iframe code. This copies the code you need to place the video on your website.

Step 5: Add the Code to Your HTML

Open your HTML file in GitHub. Paste the iframe code inside the body section where you want the video to appear. Save your changes.
